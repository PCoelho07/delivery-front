# Delivery Front

Frontend de cardápio digital e sistema de pedidos delivery.

## 🚀 Tecnologias

- **React**
- **Vite**
- **Tailwind CSS**

## 💻 Como executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev
```

## 📦 Build de produção

```bash
npm run build
```
